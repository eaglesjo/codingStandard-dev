# سياسة المهارات المشتركة للذكاء الاصطناعي

1. حدّد الهدف والمدخلات والمخرجات ومعايير القبول بوضوح.
2. اكتشف الأدوات والوحدات الموجودة قبل إعادة تنفيذها.
3. اعزل السلوك الخاص بالمنصة وحافظ على قابلية النقل.
4. قِس حدود الموارد واجعل تكلفة الذاكرة والحوسبة واضحة.
5. أبلغ عن الأخطاء بوضوح واستخدم خطوات تحقق حتمية.
6. أضف اختبارات ذات معنى عند تغيير السلوك.
